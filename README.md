# Callog(콜록)

혼자 사시는 어르신께 하루 한 번 안부를 여쭙고, 평소와 다른 신호가 보이면 가족에게 알리는 웹 서비스.

**배포**: https://help4-ax-ton.vercel.app

> ⚠️ **의료기기가 아닙니다.** 표시되는 위험도는 진단이 아니라 "확인해보세요"라는 신호입니다.
> 응급 상황에서는 119에 직접 연락해야 하며, 이 서비스는 신고를 대신하지 않습니다.

---

## 무엇을 하는가

**어르신** — 가족이 보낸 링크를 한 번 누르면 끝입니다. 계정도 비밀번호도 없습니다.
매일 짧은 안부 질문에 답하고, 원하면 말씀을 녹음하거나 가족에게 영상편지를 남깁니다.
글씨 크기·배경을 바꿀 수 있고, 질문을 소리로 읽어줍니다.

**가족** — 어르신을 등록하고 링크를 보냅니다. 어르신이 답하면 결과 요약이 알림으로 옵니다.
위험 신호가 보이면 무엇을 확인해야 하는지 알려주고, 바로 전화를 걸 수 있습니다.

## 어떻게 판단하는가

지병에 맞춘 질문을 매일 새로 만들고, 답변마다 붙은 신호를 합산해 **안전 / 위험 / 심각** 세 단계로 나눕니다.
여기에 음성 분석(발화 유무·침묵 비율·소견), 무응답 시간, 연속 외출 없음을 함께 봅니다.

애매하면 위험 쪽으로 판단합니다. 놓치는 것보다 한 번 더 확인하는 편이 낫기 때문입니다.

⚠️ **가중치는 잠정값입니다.** 근거의 등급과 한계는 [docs/근거자료-임계값.md](docs/근거자료-임계값.md)에 정리해 두었습니다 —
문헌은 방향은 지지하지만 정확한 숫자는 우리가 정한 값입니다.

## 만든 것

| | |
| --- | --- |
| 화면 | Vite · React 19 · TypeScript (`demo/v1/`) |
| 서버 | Vercel Serverless Functions (`api/`) + Vercel Cron |
| 저장소 | Supabase — Postgres · Auth · Storage · RLS |
| AI | Google Gemini — 음성 분석, 안부 질문·주제 생성 |
| 알림 | Web Push (VAPID) |

## 지켜야 할 것

- **비밀값은 절대 커밋하지 않습니다.** 모두 Vercel / Supabase 환경변수로만 관리합니다.
- **영상편지는 어떤 AI 분석도 하지 않습니다.** 개인정보 측면에서 범위에서 제외했습니다.
- **파일은 보관 기간이 지나면 자동 삭제됩니다** — 영상편지 7일, 음성 30일(받아쓴 내용은 남습니다).
- **개인정보 동의는 항목별로 분리해 받습니다** — 일반, 민감정보(건강), 국외 이전(Gemini).

## 개발

```bash
cd demo/v1
npm install
cp .env.example .env.local   # 값을 채운 뒤
npm run dev
```

`.env.local`이 없어도 화면은 뜹니다 — Supabase 미설정 배너가 보이고 데이터 기능만 비활성화됩니다.
